# Rupestre

A 2D game made in Unity for [Ludum Dare 60](https://ldjam.com/events/ludum-dare/60). The theme was **Old tech**.

- **Ludum Dare submission:** https://ldjam.com/events/ludum-dare/60/rupestre
- **Play on itch.io:** https://rascar-capac.itch.io/rupestre

## Releases

- [**Ludum Dare 60 submission**](https://github.com/rascar-capac/rupestre/releases/tag/v1.0.0-ld60-submission): the build as submitted at the end of the jam.
- [**Ludum Dare 60 submission with fixes**](https://github.com/rascar-capac/rupestre/releases/tag/v1.0.3-ld60-submission-fixed): same content, plus critical post-jam fixes.

## Project

- Unity 6000.3.9f1, URP
- Unity project in [`Rupestre/`](Rupestre), source art (Krita, Blender) in [`Sources/`](Sources)
- Credits go to Rob Tuytel for making these awesome rock textures: https://polyhaven.com/a/rock_05
- Sfxs come from https://freesound.org

### :robot: About AI

I used Claude Opus 5.5 for generating code, shaders and doing parts of the integration in Unity.

Everything else was made by myself, including animated sprites, wall model, music, brainstorming, level design, testing, etc.
